# Video evidence protocol

Retain video ID, watch-page URL, player and content URL state, thumbnail URL/status/dimensions, raw/rendered page capture, visible metadata, transcript/caption evidence, structured data, sitemap row, canonical/directives, locale/region, observed time, and first-party report row when authorized.

Validate that structured data and sitemaps describe a playable video on the target page. Separate watch-page indexability from video indexing and video-result eligibility. Treat frequent sitemap/change updates as discovery support, not an outcome guarantee.

For Key Moments, livestreams, regional restrictions, embeds, or JavaScript players, use the current platform documentation and record exact applicability. Production changes require an approved action plan and post-change recapture.
