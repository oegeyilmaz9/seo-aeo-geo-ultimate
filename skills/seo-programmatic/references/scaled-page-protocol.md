# Scaled-page protocol

For each page family record the reader task, entity/data grain, required source fields, source owner/freshness, template behavior, URL/canonical owner, editorial-readiness state, independent search/indexability state, duplicate/redirect rule, locale rule, publication condition, removal condition, affected surfaces, and verification universe.

Test normal, absent, contradictory, stale, locale-specific, and edge data. Withholding the user-facing page and excluding a URL from search are separate decisions. Publish/expand/index/noindex/redirect decisions require explicit owner approval and rollback. A shared rule is accepted only across the full affected route class or a justified closed population.
