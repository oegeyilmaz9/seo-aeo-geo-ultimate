# Image review protocol

For each material asset capture: page URL/locale, asset URL, visual purpose, nearby content, media type, intrinsic/display dimensions, delivery behavior, owner/license, and inspection time. Keep decorative assets separate.

Proposed changes need a visual/accessibility review plus an actual rendered or performance check appropriate to the issue. Use field data to describe observed user experience; use lab data to diagnose. Neither proves an image-search or ranking outcome.
