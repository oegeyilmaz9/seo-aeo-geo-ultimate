# Locale-cluster protocol

For every cluster retain: page purpose/entity, locale code, canonical URL, annotation source, target URL, observed response, content-language/market evidence, and time of capture. Validate every declared relationship in both directions and separately report canonical, redirect, indexability, content-fit, and syntax issues.

When a target cannot be accessed or its localized content is unverified, mark that condition explicitly. Do not “complete” a cluster by copying a URL into markup.
