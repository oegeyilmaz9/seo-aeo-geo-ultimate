# Sitemap inventory protocol

Create four explicit sets: URLs listed in the sitemap; URLs intended to be canonical/indexable; URLs reachable during collection; and URLs with unresolved state. Do not merge the sets into one count.

For each proposed addition/removal explain its evidence and system owner. Validate generated XML, sitemap-index references, canonical host/protocol, URL accessibility, and relevant robot discovery after deployment. Keep the official protocol and search-engine documentation current at execution time.
