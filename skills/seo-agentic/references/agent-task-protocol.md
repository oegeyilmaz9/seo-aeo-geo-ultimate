# Agent task protocol

## Task contract

Record actor, authorization, goal, start state, allowed operations, prohibited operations, required inputs, success state, irreversible steps, confirmation points, locale/device, test environment, and owner.

## Evidence surfaces

Capture the same rendered screenshot, DOM, accessibility tree, names/roles/states, form behavior, and result confirmation available to the user. Record where these surfaces disagree. An agent trace supplements but does not replace interface evidence.

## Safety and capability

Keep accessibility, security, privacy, consent, authentication, anti-abuse, and business policy requirements intact. For a protocol, record specification URL/version/status, capability discovery, operation schemas, authentication, error/fallback behavior, data owner, and last verification date. Protocol presence does not prove discoverability or use.
