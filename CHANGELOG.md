- A Claude Code plugin manifest and developer marketplace catalog that reuse the same 19 skill trees as Codex.

### Changed

- Replaced platform-specific skill-to-skill call syntax inside shared instructions with neutral specialist names.

### Changed

- Reworked the public README around the outcome users need: the next right research, audit, plan, or approved change.

### Fixed

- Clarified that `$seo` is the user-facing SEO Router command, rather than a separate generic audit skill.
