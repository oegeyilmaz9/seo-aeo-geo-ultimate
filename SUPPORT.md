# Support

## Where to ask

- Use [GitHub Discussions](https://github.com/oegeyilmaz9/seo-aeo-geo-ultimate/discussions) for setup questions, workflow ideas, and routing feedback.
- Use the issue forms for reproducible bugs or scoped improvement proposals.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a change.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities; do not disclose them in a public issue.

When asking for help, include the skill you called, the intended outcome, the smallest safe reproduction, and any validation output that is safe to share.
