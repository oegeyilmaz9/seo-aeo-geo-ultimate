# Keyword decision template

Use privately as `keyword-decisions.md` after [research qualification](../skills/seo-research/references/keyword-research-protocol.md). This template has no market observations; fill it from actual sources and pin the supporting Query Corpus/raw evidence.

## Scope and provenance

Declare product truth, reader tasks, language, market/location, device, engine/surface, collection date/window and source method. List owner-required target families and exclusions with reasons. Preserve source definitions for volume, trend, CPC and difficulty; unavailable stays unavailable.

## One decision per compatible intent cluster

| Field | Required record |
| --- | --- |
| Query and need IDs | Actual Query Corpus IDs and aliases |
| Primary/supporting intent | Reader task and dated representative SERP evidence |
| Demand | Actual provider, market/window and known aggregation limits, or unavailable |
| Ambition track | Near-term capture and/or owner-required category/head-term leadership |
| Canonical HTML owner | One real owner or explicitly planned new owner |
| Markdown answer | Exact approved document and stable answer-section destination |
| Coverage/gap | Answer completeness and source/public access limitations |
| Cannibalization | Actual competing owner/intent evidence and retain/merge/split/no-action decision |
| Action and rationale | Evidence-linked create/improve/consolidate/maintain/defer decision |
| Priority and owner | Business fit, demand evidence, gap, effort and dependencies kept distinct |
| Verification | Source parity, direct-link/task check and subsequent separately observed measures |
| Refresh | Trigger/date and maintenance owner |

## Acceptance

Every decision-driving family has evidence or an explicit dependency. Missing demand is not a fabricated score. Lexical similarity alone does not justify merging pages. Preserve important head terms even when difficult; document sequencing instead of quietly dropping them. No decision claims rank, AI citation or accessible answer delivery solely from a generated file.
